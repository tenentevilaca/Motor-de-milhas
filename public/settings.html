1. Comparação em dinheiro real

Essas fontes alimentam o detector de erro de tarifa / promoção relâmpago com preços reais, sem precisar falar diretamente com o site de cada companhia. Configure quantas quiser — quanto mais fontes, melhor a chance de pegar um preço fora da curva.

SerpApi (Google Flights) verificando…

1. Crie uma conta grátis em serpapi.com (100 buscas/mês grátis) · 2. No painel, copie sua "Private API Key".

Kiwi.com Tequila verificando…

1. Crie uma conta grátis em tequila.kiwi.com · 2. Peça acesso de API (aprovação costuma ser automática/rápida) · 3. Copie a "API Key".

Travelpayouts verificando…

1. Crie uma conta grátis em travelpayouts.com (geralmente só e-mail, sem telefone) · 2. No painel, gere um token de API (seção "API" da conta) · 3. Cole abaixo. Retorna o menor preço já visto recentemente pra rota — mais uma fonte independente pro detector de anomalia.

2. E-mail (SMTP) verificando…

Mais fácil: Brevo (300 e-mails/dia grátis). 1. Crie a conta · 2. Vá em "SMTP & API" → "SMTP" · 3. Copie host, porta, login e senha SMTP (não é a senha da sua conta). Alternativas: Resend, ou Gmail com "senha de app".

3. WhatsApp — opção simples: CallMeBot verificando…

Sem cadastro em site nenhum. 1. Salve o número +34 644 59 71 67 nos seus contatos · 2. Pelo seu WhatsApp, mande a mensagem I allow callmebot to send me messages pra esse número · 3. Em poucos segundos você recebe de volta uma mensagem com sua "API Key" — cole ela abaixo. Serviço gratuito de terceiros (não é do WhatsApp/Meta), pensado pra uso pessoal — se parar de responder, é só mandar a mensagem de novo pra reativar. Mais detalhes: callmebot.com.

3b. WhatsApp — opção avançada: Twilio verificando…

Mais robusto que o CallMeBot, mas exige conta com verificação de telefone/cartão. Só configure se o CallMeBot acima não atender (ex: quer usar em produção com vários números). 1. Crie uma conta grátis em twilio.com/try-twilio · 2. Account SID e Auth Token ficam no painel principal (console.twilio.com), no card "Account Info" — se não aparecer, veja no menu da conta (ícone no canto superior direito) → "API keys & tokens" · 3. Vá em Messaging → Try it out → WhatsApp Sandbox e copie o número "From" (algo como whatsapp:+14155238886) · 4. Importante: pelo seu celular, envie a mensagem "join <código mostrado na tela>" para esse número — sem isso, o Twilio não entrega as mensagens, mesmo com tudo certo aqui. Esse opt-in expira em 72h no modo sandbox e precisa ser refeito.

3c. Telegram (provavelmente o mais fácil de todos) verificando…

1. Fale com @BotFather no Telegram, mande /newbot e siga as instruções — ele te devolve um token · 2. Procure o bot que você acabou de criar (pelo username que você escolheu) e mande qualquer mensagem, tipo /start · 3. Cole o token abaixo e salve · 4. Volte na tela principal, no campo de Telegram, clique em "Descobrir meu Chat ID".

4. Milhas (AA / LATAM Pass / Smiles / TudoAzul)

Nenhuma dessas companhias tem parceiro público pronto pra oferecer aqui como opção — por isso a lista abaixo tem só duas escolhas por programa: deixar "não configurado" (o app mostra um link para checagem manual, que já é o esperado pra maioria das pessoas) ou informar a URL de uma integração que você mesmo tenha (parceria oficial, GDS, ou serviço que você administre e esteja autorizado a rodar).
